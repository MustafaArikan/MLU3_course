# Week 4

GPU and PyTorch.

* **`00_Download_Data.ipynb`**: Get the STL-10 data
* **`01_Tensors.ipynb`**: Some basic tensor operations
* **`02_Vectors.ipynb`**: norms, dot product, cosine similarity, vectors
* **`03_ to 07_`**: Embeddings with pre-trained model, Autoencoder and embedding gemma 2

## Technical Requirements

Managed via `uv`. PyTorch is pinned to the CUDA build (`2.10.0+cu128`)
